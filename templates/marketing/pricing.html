Common questions

Where does the guest's money go?

Straight to your Paystack account or M-Pesa till. Pingota receives the payment confirmation and switches the router on.

What happens when a pass runs out?

The router ends the session. Each hotspot user carries a router-side time limit, so access ends even if the panel is down. The panel then removes the stale user.

Can I run it on my own server?

Yes. The code is MIT licensed and the installation guide covers Docker, Dokploy and a no-Docker install. Export the database and run the same image.

Does it work behind CGNAT?

Yes. Each router dials out over TunGuard's WireGuard-compatible tunnel, so it needs no public IP and no port forwarding. The API port is reachable only from inside the tunnel.

Is the trial really free?

Yes. The trial lasts 24 hours and needs no card. We review each request during support hours before the panel is created.

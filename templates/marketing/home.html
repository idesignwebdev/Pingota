Monitoring and management panel

Live access

Every active pass in one list, with the device, package, router and time left. You can add time, revoke a pass, or disconnect a session while keeping the pass for a reconnect.

  • Add minutes to a pass without asking the guest to pay again.
  • Revoke a pass when a device is shared or abused.
  • Disconnect one device without touching the rest of the network.
  • See which router carries each pass.

Speed and data per pass

Each pass can carry a download and upload limit, an optional data allowance, and a slow profile for fair use. The router applies the limit and keeps it across reconnects.

Router health, not guesses

Pingota samples CPU, uptime, latency and the online count once a minute. A router that stops answering is marked unreachable and the event log keeps the record.
